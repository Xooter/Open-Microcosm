# Prepared plates: `plates/<id>.toml`

A `[[plate]]` is a ready-made laboratory preparation besides the water drop: a cell culture or a
slide ([prepared plates](../mechanics/prepared-plates-and-tissues.md)). Registry: `game/prepared`.

| Key | Meaning |
|---|---|
| `id`, `name`, `description`, `legacy_ids` | Identity. |
| `kind` | `cell_culture` or `slide`. |
| `medium`, `vessel` | Ids ([media.md](media.md), [vessels.md](vessels.md)). |
| `field_um` | Side of the simulated field. |
| `cell_um` | Grid resolution. |
| `fixed` | Dead and still (smear, section). |
| `stain` | Id of the stain applied on creation. |
| `erythrocytes_cm2`, `platelets_cm2`, `bacteria_cm2` | Densities. |

## `[plate.environment]`

`temperature` [°C], `co2` (fraction of the air), `light`.

## `[[plate.seeding]]`

`being` (id) and `density_cm2` [cells/cm²].

## `[plate.tissue]`

A plant tissue: cellulose walls generated by an arrangement and a living protoplast in each cell.

| Key | Meaning |
|---|---|
| `arrangement` | `rows`, `polygonal`, `files`, `jigsaw`. |
| `content` | `protoplast`, `starch`, `mitosis`, `stomata`. |
| `being` | The protoplast's being id. |
| `length_um`, `width_um` | Cell size. |
| `wall_um` | Wall thickness. |
| `sap_osmolarity` [mOsm/L] | Cell sap osmolarity (plasmolysis threshold). |
| `inactive` | Osmotically inactive fraction. |
| `equilibration_s` | Real-time seconds to osmotic equilibrium. |
| `mitotic_phases` | Fractions [prophase, metaphase, anaphase, telophase]. |
